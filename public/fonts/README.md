# Font provenance

Geist and Geist Mono Latin variable WOFF2 files are sourced from the installed Next.js 16.3.2 distribution (`next/dist/next-devtools/server/font`). Both are Vercel's Geist font family, distributed under the SIL Open Font License 1.1; see OFL.txt. They are self-hosted through next/font/local so production builds and visits do not request Google Fonts.
